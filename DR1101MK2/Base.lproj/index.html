DR-1101 MK2 使い方
eighty-seven DR-1101 MK2
・最大32ステップ（無料版は16ステップ）のシーケンサーを備えたハイブリッドリズムマシン（シンセ音源＆サンプリング音源）
・グリッドによる直感的なステップ入力、3段階ベロシティとフラム機能搭載
・任意のサンプルを取り込み可能（MK2版）
・16×4パターンを組み合わせて複数のソングを構築可能
・CHST/MASTER EQ・COMP、REVERB、SEXY PADなど多彩なエフェクトを搭載
・CLOCK OUTにより外部機器との同期が可能
▶ 画面の切り替え
・SEQUENCER画面上部のDRUM／BASS／MIXボタンで画面を切り替え
・DRUMを押すたびにDRUM PTN（通常のグリッド）⇄DRUM EDIT（パートごとのTUNE/LEVEL/DECAY/TONE）をトグル
・BASSを押すたびにドラム画面⇄BASS EDIT（ピアノロール入力）をトグル（MK2版）
・MIXでMIX画面へ
▶ 基本操作
・START/STOP（またはスペースキー）で再生/停止
・TEMPOノブでBPM調整（ドラッグまたは±ボタン）
・STEPノブでステップ数変更（無料版は1〜16、MK2版は1〜32）
・SWINGノブでグルーブ感を追加
・1-16／17-32ボタンで表示ステップページを切り替え（17-32はMK2版のみ）
・COPY／PASTEで表示中の16ステップ分をコピー＆貼り付け、CLRでクリア（MK2版のみ）。ドラムはCOPY/PASTE/CLRで全パート＋フラムが対象、BASSはノート/ACCENT/SLIDE/TIEが対象
▶ ステップ入力
・LCDのマス目をタップ/クリックでON/OFF
・VELボタンONで 弱→中→強→OFF のサイクル入力（FLMと排他）
・FLMボタンONでフラムモード：ノートのあるマスをタップしてフラムON/OFF（右上に三角マーカー点滅）
・フラムONのステップは28ms前に小さなゴーストヒットが入る
・ノートを消すとフラムも同時にクリアされる
・ドラッグで連続入力可能
・CHラベルをダブルタップでOH/CH排他モード切り替え
　通常表示（暗い背景）= TRモード：同ステップはOH優先、CHのタイミングでOHリリースをカット
　反転表示（明るい背景）= 同時発音モード：OH・CH同時発音可、ただしCHのタイミングでOHリリースはカット
・無料版はT1/T2が「ー」表示になり使用不可（実機準拠の6パート構成）
▶ パターン管理
・PAT 1〜16でパターン切り替え（再生中は1小節末に反映）
・BANK A〜Dでバンク切り替え（64パターン、無料版はA/Bのみ）
・編集した内容は WRITE を押すまで保存されません
・別パターンに移動すると編集内容は破棄されます
・WRITEボタンが点灯（ピンク）= 未保存の変更あり
・WRITEボタン点灯中に別のパターンを選ぶとそこに書き込み（バンクをまたぐコピーも可能・停止中のみ）
・FILLボタンでFILLモード：パターン13〜16がFillパターンとして機能。再生中にFillパターンを押すと1小節だけそのパターンを再生して元のパターンに戻る
・UNDOで直前の操作を取り消し
▶ フッター（画面下部）
・1段目：Sound Set A〜E タブ。押すとその場でサンプル＋MIX/FX設定一式を切り替え
・2段目：START/STOP（再生/停止）／REC／CLEAR／WRITE／FILL／BANK A〜D
　－REC：停止中に押すと再生を始めながら録音待機、再生中に押すとその場で録音待機になり、グリッドをタップするとリアルタイムにノートが入力されます。もう一度押すと録音終了
　－CLEAR：表示中のワークパターンを全消去（WRITEするまで未確定、UNDOで戻せます）
　－BANK：タップでバンクA→B→C→D→Aの順に切り替え（無料版はA/Bのみ）
・3〜4段目：PAT 1〜16 パターン選択ボタン（再生中に押すと1小節の頭で切り替わり、FILLモード中は13〜16がオレンジ表示のFillパターンになります）
▶ MIX画面
・パートごとに縦一列（BD/SD/T1/T2/CP/CH/OH/CY/BASS/マスター）：上からTRIM（入力ゲイン）／REV（リバーブ送り量）／CHST（チャンネルストリップ選択）／PAN／SOLO／縦フェーダー／MUTE
・BASSチャンネルはMK2版のみ表示
・CHSTボタンでそのチャンネルをCHST(1176スタイルCOMP＋3バンドEQ)の編集対象に選択、画面中央の帯で詳細調整（INPUT/ATTACK/RELEASE/RATIO/OUTPUT、LO/MID/HI GAIN）
・CHST欄のEZY：COMPを詳細5ノブ⇄簡易2ノブ表示に切替。PRE：EQ→COMPの順⇄COMP→EQの順を切替
・REVERB：SIZE/DECAY/GATE/VOLの4ノブ。SCH（軽量アルゴリズム）とIR（高品質コンボルーション）を切替可能
・MASTER：SSL BUS COMP仕様のコンプ（THRESH/ATTACK/RELEASE/RATIO/MAKE UP）＋MASTER EQ（6バンド、各バンドのゲインを個別調整）を搭載。ONボタンでコンプのバイパス切替
・SEXY PADセクションは下記「SEXY PAD」の項を参照
▶ SEXY PAD
・マスター出力後段に挿入するX/Yパフォーマンスエフェクト（KAOSS PAD風）
・FX1〜FX4を直列に接続、各スロットのエフェクトタイプを選んでX/Yパッドで操作
・PERFORM：モーメンタリー動作（離すと中央復帰）、TOUCH：タッチ中のみエフェクト有効、MUTE：バイパス、FREEZE：値を固定
・プリセット1〜20は無料版でも使用可、21〜100はMK2版で解放
▶ Sound Set
・Sound Setは8パート分のサンプル＋MIX/FX設定をまとめて保存したセットです
【サンプルを登録する手順】（MK2版）
① SETTINGタブ → SAMPLE LOADエリアで各パートにWAVをロード
② MIX/FXを好みに調整
③ SAVE SOUND SET A〜D のいずれかを押して保存
【切り替え】
・フッターの Sound Set A〜E をタップで即時切り替え
・Sound Set E = 全パートを合成音にリセット（サンプルなし）
【他の人と共有する】
・EXPORT SET A〜D（緑ボタン）でサンプル込みのJSONファイルを書き出し
・受け取った人は IMPORT SET（青ボタン）でJSONを選択して読み込み
・データが空のスロットはボタンが薄く表示されます
▶ SETTING画面
・DRUM SET欄：プルダウンでSound Set A〜Eを選択し、EXPORTでサンプル込みJSON書き出し、IMPORTで読み込み
・SAVE A〜D：現在のサンプル＋MIX/FX設定をそのスロットにSound Setとして保存（MK2版）
・GLOBAL欄：DRUM LOCK／BASS LOCK／MIX LOCKをONにすると、それぞれドラム/BASS/MIXの内容がパターン切替時に固定され、変更されなくなります
・CLOCK OUT：外部機器へのクロック出力ON/OFF（MASTERのMONOがONの時のみ設定可）。右のプルダウンで÷1（通常）／÷2／÷4／÷8／×2 の出力レートを選択
・S/M QTZ：START/STOP操作を小節の頭にクオンタイズ（合わせる）するか切替
・EXP JSON ALL／IMPORT ALL：全バンク（A〜D）をまとめて書き出し/読み込み。EXP JSON／IMPORT：現在のバンクのみ対象
・ENABLE SHAKE UNDO：ONにすると端末を振ることでUNDOを実行できます
・SHOW LOAD METER：ONにすると発音数（VOICES）とCPU負荷（%）のメーターを画面に表示
・BAKE HTML：現在の全データをHTMLファイルに焼き込んでダウンロード（詳細は「データ管理」の項）
・画面上部のFREE／MK2切替で無料版とMK2版の動作を試せます（開発・確認用）
▶ SONG MODE
・最大16スロットにパターンを並べて再生（無料版は1〜2スロットのみ）
・上段ツールバー：▶ PLAY／■ STOP、SONG 1〜16切替（保存済みソングの呼び出し）、＋ADDで現在のパターンを末尾に追加、CLEARでソング全体を消去
・SOUND SETプルダウン：このソング再生中に使うSound Setを指定（GLOBAL=切替なし、A〜E=固定）
・スロット一覧の列：BNK/PTN（バンク・パターン）、RPT（そのスロットの繰り返し回数）、COMMENT（メモ）、BPM（GLOBAL=再生開始時のBPMを使用／INPUT=スロットごとに指定）、BPM VAL（INPUT時の数値）、✕でその行を削除
・行をドラッグで並べ替え可能
▶ データ管理
・編集内容は自動保存（次回起動時に復元、WRITE前の未確定な編集は保存されません）
・EXPORT JSONでバンクA〜D別に4ファイルを書き出し（dr1101_bankA.json〜D.json、MK2版）
・IMPORT JSONでバンク別ファイルを読み込み（バンク別ファイルはそのバンクのみに反映、MK2版）
・BAKE HTMLで現在の全情報（パターン・サンプル・MIX・FX・BPM）をHTMLに焼き込んでダウンロード（DR1101_baked.html、MK2版）。別端末で開くだけで即使用可能。LOAD ALL PRESETで焼き込んだパターンも呼び戻せる
・LOAD ALL PRESETでプリセットを読み込む（ユーザープリセットがあればそれを優先）
　工場プリセット: Bank A=テクノ(140BPM) / B=ヒップホップ(88BPM) / C=ドラムンベース(170BPM) / D=レゲエ(80BPM)
・LOAD ALL PRESET をダブルタップで現在の全バンク×パターンをユーザープリセットとして保存
▶ 無料版とMK2版の違い
・無料版：ドラム6パート(T1/T2使用不可)、STEP最大16、BANK A/Bのみ、SONGスロット1〜2のみ、サンプル読み込み不可、SEXY PADプリセット1〜20のみ、BASS非搭載
・MK2版：ドラム8パート、STEP最大32(17-32ページ＋COPY/PASTE/CLR)、BANK A〜D、SONGスロット1〜16、サンプル読み込み・EXPORT/IMPORT JSON・BAKE HTML、SEXY PADプリセット全100、BASS搭載
▶ LOCK / CLOCK OUT
・MIX/REVERB/FX1/FX2を個別ロックでパターン切替時に設定固定
・CLOCK OUTでオーディオパルス + MIDIクロックマスター出力
